# PuzzleBox 🧩

PuzzleBox is a browser-based brain game arcade with three mini-games designed to test memory, number reasoning, and pattern recognition.

## 🎮 Games

### 🧠 Memory Match
Find all 8 matching pairs using as few moves as possible.

### 🔢 Number Sequence
Find the missing number in different mathematical sequences.

### 🔷 Pattern Puzzle
Study the pattern and choose what comes next.

## ✨ Features

- Three playable brain games
- Score system
- Randomized Memory Match cards
- Randomized Number Sequences
- Multiple Pattern Puzzle challenges
- Responsive design for desktop and mobile
- Simple, clean game interface
- No account or login required

## 🛠️ Built With

- HTML
- CSS
- JavaScript
